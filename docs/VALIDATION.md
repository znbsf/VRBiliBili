# 桌面原型验证

日期：2026-10-01。初始仓库基线在推送前重新执行原型相关回归；具体结果记录在 [validation-results.json](validation-results.json)。

| 检查 | 覆盖 |
| --- | --- |
| 静态 10 项 | JS 语法、唯一 ID、动作处理、无远程资源、文档链接 |
| DOM 31 项 | 进度、历史、返回、布局、锁定/跟随、旧/损坏状态；不是像素验证 |
| 核心浏览器 42 项 | 320/736/1024/1280px、浅/深色、实际鼠标/键盘/拖动、刷新 |
| 健壮性浏览器 43 项 | 快速点击、重绘后 Escape、动态尺寸、完整预设状态、损坏/旧存储与两次浏览器关闭重开 |

真实浏览器检查使用已有 Chromium、独立临时配置和本机单文件服务器，不使用用户浏览器窗口。设置组合中的部分字段用原生 DOM input/change 事件；鼠标、Escape、拖动与指定键盘步骤使用 CDP 浏览器输入。

原型使用虚构内容与模拟计时。结果不覆盖真实账号、视频/音频、XR、Quest、主观视觉或舒适度。最终平台路线与河流效果是否发布仍需后续用户/设备验证。

完整本机日志、截图、备份与机器环境记录保留在被忽略的本地目录。仓库摘要只包含用例名称、结果、浏览器版本、时间和源/预览哈希，不包含个人路径、浏览器配置或进程信息。

初始仓库没有 CI 工作流。远端工作流、运行和提交检查状态在初次推送后单独核对，不能由本地通过替代。
