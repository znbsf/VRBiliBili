# 隔离恢复验证与公开边界（2026-10-04）

当前版本为实验性源码。整合以 `796763a5e2ab2e68b84dea08ef2f00a692a51801` 为父基线，接收原目录在研界面变更及恢复修复。后续的 `CinemaControl.kt` 图标/焦点标签行为和 `quest-client-validation.json` 实机结果原样保留。源码公开不代表头显体验已完成人工验收，也不发布包含 Meta SDK 的组合 APK。

## 已修复的恢复问题

- Flutter 画质加载可等待；原生播放期间只解析已有 DASH 视频/音频地址，避免启动第二个 Flutter 解码器。返回时等待暂停加载并恢复进度，清理失败也会释放入口状态和回调。
- Preview 用请求序号和会话代次拒绝关闭后或旧会话的画质回复；后台收到回复保持暂停。真正头显路径的画质回复同样检查前台状态和空间焦点，其他空间状态不会沿用旧焦点值。
- 切集时详情 CID 可以早于解码器更新。入口拒绝查询中或 CID 不一致；回调和跨异步边界重新检查详情、播放器及控制器存活状态，缓存写入也核对目标 CID。
- 网络视频完成态缓存不再读取仅离线初始化的 `entry`。截图验收会拒绝旧图、缺失图、损坏图、错误尺寸和失败进程。

## 实际验证结果

| 验证 | 结果与覆盖 |

| 静态 / DOM 流程 | 10 项静态与 31 项 DOM 通过；DOM 不渲染浏览器像素 |
| Dart 恢复逻辑 | 17/17；等待加载、异常清理、关闭租约、CID 变化及延迟回复 |
| Kotlin 回调保护 | 9/9；另有此前独立 Preview 的 6 项真实 ExoPlayer 生命周期/画质回归通过 |
| Python 截图工具 | 20/20；外部设备调用全部模拟 |
| 最终 Android 构建 | 独立目录、离线锁定依赖、单工作进程构建通过；未修改系统 SDK、代理或用户工程目录 |
| 真实 Flutter → 原生 → 返回 | 全新无窗口 Spatial Simulator 的 7 项通过；实际离线下载入口、MediaKit 解码、MethodChannel、生产 CinemaPlayer/Preview、暂停与进度恢复、再次进入及第二 CID 缓存隔离 |

真实交接没有替换 `CinemaSession.request` 或仿造 Flutter 播放器。使用仓库自生成的 6 秒本地 fixture，无账号登录或真实 B 站视频。调试入口仅在 `kDebugMode && QuestDevice.isQuest` 中用于状态观察和实际入口防护探针。

第一轮真实测试在第二 CID 导航阶段要求旧缓存逐字相等而失败：页面销毁会按解码后的实际位置补写进度。修订后仅在该导航阶段允许 400 毫秒帧量化差，要求两 CID 的位置相差超过 800 毫秒，并以完成导航后的旧 CID 缓存作为后续严格不变基线。最终实测 A 缓存从 2673 到 2750 毫秒，B 初始位置 666 毫秒；B 原生返回后 A 仍为 2750 毫秒。

最终 A 返回位置 2583 毫秒、缓存 2581 毫秒；B 返回位置 2083 毫秒、缓存 2048 毫秒。两次返回后实际 MediaKit 都保持暂停，并额外观察 650 毫秒防止延迟恢复播放；重入同时核对传递位置和首个解码位置，不能靠从零播放追上目标位置通过。
