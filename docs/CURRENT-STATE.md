# 当前状态：普通 Android 面板

唯一推荐目标：普通 Android 大屏播放，保留原有选片/UI/账号/弹幕/画质能力，同页展开收起、单一圆点进度条、松手后一次 seek、等比 cover 裁切。当前产品运行时已隔离 Meta/XR；历史影院源码保留追溯，不恢复影院入口。

当前本地待发布候选为 `v0.1.0-rc.7 / code 7`（尚无远端发布），精确构建源码 `1568ef4b0fc99306f184e5560dacd65a33426e0f`。main 通过正常快进纳入代码，后续文档仅补记实际结果。rc.7 禁用上游自动更新，手动入口只开本项目发布页。

16 项组件测试、范围静态分析、正式构建与 code 7 Quest 保数据升级通过。实际正确鼠标/触屏拖动、返回 0:17 续播、暂停 0:30 自然休眠后正常唤醒恢复、手动更新 URL 已验证。旧无按键 mouse 注入失败属于测试输入问题，没有为此改写生产播放器。真实窗口像素已取得，但 cover 会裁去字幕/水印边缘。

分发状态：本地 main 已归并且干净；自动审批以原始“不要推送”限制拒绝 push，后续授权原文读取失败，因此没有绕过，也没有创建 rc.7。远端 main 仍为 de4509e，公开最新仍是 rc.6。先由父任务确认本次推送/预发布授权后正常推送并校验五个附件；不移动 rc.6。

体验优先下一步：在不回到影院开发的前提下，验收实体手柄/手势、完整播放中休眠循环、典型比例与字幕可读性、长时音画同步。若必须完整显示字幕/边缘，需单独决定是否提供 contain/cover 切换；当前不擅改既定 cover 行为。上述缺口完成前保持 prerelease。
